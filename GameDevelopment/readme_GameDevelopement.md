# GameDevelopmentの説明

## プロジェクトについて
タイトル：星ノ秘密
ジャンル：遺跡探索型ウォーキングシミュレータ
テーマ：没入体験,未知の探究
概要：ダイス型コントローラーを用いてヒントを集めながら、未知の遺跡からの脱出を目指すゲーム
制作期間：2024年10月 ~ 2025年9月
制作人数：10名(+一部外注)
使用ツール：Unity,CRI ADXLE
担当個所：サウンド面の実装全般,サウンドデザイン

## 全体を通しての設計のポイント
1.サウンドが果たすべき役割の意識
    このゲームは1人称視点で進行し、プレイヤーキャラクターの手足などは視覚的に登場しません。
    そのため、歩行のようなプレイヤーキャラクターの動作はすべてサウンドのみによって表現する必要がありました。
    ゲームのテーマとして掲げた没入体験を実現するために、ミドルウェアの機能を応用的に利用しつつ、スクリプト側でこだわりを持った制御を行いました。
    チームメイトや講師から何度もフィードバックを受けつつ、ゲーム全体の没入感の演出に貢献できるサウンドの実装を行いました。
2.チームメイトのプログラマとの協働
    一般的な開発では後工程になりがちなサウンド実装ですが、このプロジェクトでは展示の機会などがある場合に、そもそも十分なサウンド実装時間が確保できないという事態が発生しました。
    チームメイトの開発とサウンド側の開発を上手く並行して進めるために、発音処理をはじめとするサウンド側のスクリプトはあらかじめすべて用意しておき、他の担当者に呼び出しのみを組み込んでもらうという作業の流れを取りました。
    これに付随して事前の綿密なコミュニケーションや、情報の共有を行ったことで、この手法はサウンドだけではなくゲーム全体の質を高めることに繋がりました。

## 収録ファイル
- S_ADX3DPos.cs : スキルで発見したオブジェクトと敵の移動音を3DPositioningを用いて実装した。
- S_ADXCommands.cs : サウンド実装作業の手間を省略するための関数を用意した。
- **S_ADXFootSteps.cs** : 没入感を演出する足音の表現を行った。
- **S_ADXKagee.cs** : デバイスを用いた特殊なインタラクションとゲームのメカニクスを接続するサウンド表現を実装した。
- **S_ADXPlayer.cs** : 他のメンバーとの協働を意識した、外から呼び出すための関数群。
- S_CueSheet.cs : ADXのビルド時に自動で出力される、ADXの情報をまとめたファイル。このプロジェクトではこのファイルに含まれるenumを用いた再生指定を行った。

※『S_』はサウンドのスクリプトであることを明瞭にするため、チーム内で定めた接頭辞です。
